HWK QIP Incentive 시스템 — AQL Allowance 신규 기능 안내

발행일: 2026-05-04  |  대상: Quality 부서 / Incentive 운영 담당자

요약: AQL 검사에서 reject된 PO를 정당한 사유와 함께 등록하면, 영향받는 모든 직원의 인센티브 조건(C5~C8)이 자동 면제 처리되어 인센티브가 재계산됩니다. 관리자가 PO 번호만 입력하면 시스템이 영향 직원과 인센티브 변동을 자동 산출합니다.

1. 왜 이 기능이 필요한가?

기존 인센티브 시스템에서는 AQL Reject가 발생하면 그 PO를 검사한 모든 직원의 C5~C8 조건이 NO로 처리되어 인센티브를 받지 못했습니다. 그러나 그 reject가 직원 책임이 아닌 사유(원자재 결함, 설비 오작동, 외부 요인 등)로 인한 경우 부서장이 PO 단위로 면제 처리할 수 있어야 합니다.

3. 사용 절차 (AQL Allowance)

  1. 관리자 페이지 → "AQL Allowance" 탭으로 이동
  2. 월/년도 선택 (해당 PO가 검사된 월)
  3. PO 번호 입력 후 Enter (복수 가능, 예: 902078209, 902225040)
  4. 근본 원인 입력 (예: 원자재 결함으로 인한 외관 불량)
  5. 액션 플랜 + 마감일 입력 (예: 공급사 시정 요구 + 입고 검사 강화 / 2026-05-31)
  6. 필요 시 사진/문서 첨부 (최대 3개, 각 2MB 이하)
  7. 면제 조건 체크박스 확인 (기본: C5/C6/C7/C8 모두)
  8. [영향 직원 미리보기] 클릭 → 시스템이 매칭된 행, FAIL 건수, Reject 수량, 영향 직원 명단 + 인센티브 Before/After를 자동 표시
  9. 확인 후 [AQL Allowance 적용] 클릭 → 영향 직원의 인센티브 자동 재계산

4. 자동 처리 항목

  • 영향 직원 자동 식별: 입력한 PO 번호와 매칭되는 모든 AQL 검사 행에서 직원 번호 추출
  • C5~C8 자동 재계산:
    • C5 (개인 AQL FAIL): PO 면제 후 직원의 FAIL 건수가 0이 되면 PASS
    • C6 (연속 AQL FAIL): 이번 달 C5가 PASS면 면제 후보로 처리
    • C7 (팀/구역): 본인 C6 면제 시 면제
    • C8 (구역 Reject율): Building별 reject율 재계산하여 임계값 미만이면 면제
  • 인센티브 재계산: 면제 후 Pass Rate가 100%에 도달하면 progressive table 또는 Position 배수에 따라 자동 산정
  • 대시보드 자동 반영: 직원 모달의 C5~C8 행 옆에 파란색 "AQL Allowance" 뱃지 표시 + KPI 카드 즉시 갱신
  • 매시간 파이프라인 보호: 등록된 AQL Allowance는 매시간 파이프라인 실행 후에도 자동 재적용되어 덮어쓰기 방지

5. 액션 플랜 추적

등록된 PO Allowance에는 액션 플랜과 마감일이 포함됩니다. 액션 상태(계획 / 진행중 / 완료)를 admin 페이지에서 변경할 수 있으며, 직원 모달에서도 모든 영향 직원의 액션 플랜 진행 상황이 표시됩니다.

6. 데이터 무결성 보장

  • 원본 보존: 모든 Allowance 적용 시 원본 conditions / pass_rate / incentive 값을 스냅샷으로 별도 저장 → Revoke 시 100% 복원
  • 감사 추적: 적용자 이메일, 적용 시각, 철회자, 철회 사유 모두 기록
  • 중복 방지: 동일 PO를 두 번 등록하면 시스템이 차단
  • 권한 분리: Firestore 규칙으로 일반 사용자는 읽기만 가능, 관리자만 쓰기 가능

7. 협조 요청 사항 (담당자 → 부서장)

다음 사항을 부서장과 면담하여 정책을 명확히 정해 주시기 바랍니다:
  1. AQL Reject PO에 대한 Allowance 승인 권한자 명단 (현재는 admin 권한자 모두 가능)
  2. 등록 시 필수 첨부 자료 종류 (예: 품질 부서장 결재 사본, root cause 분석 보고서 등)
  3. 액션 플랜 마감일 표준 (예: 등록일로부터 30일 이내 등)
  4. 면제 사유로 인정 가능한 외부 요인 카테고리 명문화 (원자재 결함 / 설비 오작동 / 천재지변 / 회사 지시 등)
  5. 월별 Allowance 등록 통계의 QOS 보고 주기
